{{ octicon("shield-check", 16) }} Architectural Guardrails

Inspect active policies →
{{ octicon("shield-check", 20) }}

Never Touch Tests

Test suites, mocks, and CI workflows are strictly immutable. Patchwork only modifies application code, never the tests asserting behavior.

{{ octicon("checklist", 20) }}

Diff Size Limits

Hard limits (default 50 lines) prevent runaway code rewrites. If a proposed fix requires touching half the codebase, it is safely rejected.

{{ octicon("sync", 20) }}

Infinite Loop Defense

Branches prefixed with ai-fix/ are automatically excluded from triggering secondary jobs, eliminating circular CI storm risks.

{{ octicon("server", 20) }}

Isolated Sandbox

Every patch must execute and pass the project's real test suite locally in Docker or a sandboxed subprocess before any Git push.
